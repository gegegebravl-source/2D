# EXFIL — 2D-rooted 3D extraction shooter (аналог Escape from Tarkov)

Проект на **Unity 6 (`6000.0.x`)**. Игра ведётся **от первого лица в 3D**: убежище-бункер и боевые рейды.
Данные и логика (предметы, сеточный инвентарь, баллистика, здоровье, крафт, грядки, ИИ, экономика) написаны
движко-независимо и одинаково работают и в 3D, и в гипотетическом 2D-режиме — это та самая «2D-основа».

> Статус: **играбельный каркас**. Геометрия, оружие и персонажи — процедурные заглушки из примитивов,
> которые одной кнопкой заменяются на реальные модели (см. [Assets/Art/MODELS.md](Assets/Art/MODELS.md)).

## Быстрый старт

1. Клонируйте репозиторий и откройте папку как Unity-проект (Unity Hub → Open → Add project).
2. Первый запуск: меню **EXFIL → Setup → Run full setup (one click)**.
   Он создаст весь контент (предметы, 6 операторов, модули бункера, рецепты, растения, торговцы, боты, квесты),
   базу предметов, префаб игрока и две сцены: `Assets/Scenes/Hideout.unity` и `Assets/Scenes/Raid.unity`.
3. Рекомендуется один раз запустить **EXFIL → Setup → 6 - Install URP (рекомендуемый)** и после установки
   **Apply URP to graphics settings** (иначе будет стандартный Built-in рендер — тоже работает).
4. Откройте `Hideout.unity` и нажмите **Play**. Из бункера можно выйти в рейд через терминал/дверь (или
   поставить `AutoStartRaid` на `GameBootstrap`).

### Управление

| Клавиша | Действие |
|---|---|
| `WASD` | ходьба, `Shift` — бег, `C` — присед, `X` — лёжа |
| мышь | обзор, `ЛКМ` — огонь, `ПКМ` — прицеливание |
| `R` | перезарядка, `B` — режим огня, `T` — проверить патронник |
| `E` (удерживать) | обыск/взаимодействие (ящики, тела, станции бункера) |
| `1..3` | основное / вторичное / кобура, `Q` — переключить оружие |
| `H` | использовать предмет из быстрого слоя 4 |
| `Tab` / `I` | инвентарь, `Esc` — закрыть окно |

## Что уже реализовано

### Ядро (`Runtime/Core`)
- **Services** — локатор сервисов, **GameEvents** — типизированная шина событий (выстрел, урон, смерть, экстракт, урожай, тик убежища).
- **Rng** — детерминированный xorshift: рейд с одним сидом = одинаковый лут и спавны.
- **EXFILInput** — единый ввод, работает и через новый Input System, и через старый Input Manager.
- **GameSettings** — чувствительность, FOV, громкость, авто-перезарядка.

### Персонаж и бой (`Runtime/Characters`, `Runtime/Combat`, `Runtime/Player`)
- 7 отдельных зон здоровья (голова, грудь, живот, руки, ноги), «чёрные» конечности с разбросом урона,
  кровотечения (лёгкое/тяжёлое), переломы, боль, контузия, обезвоживание, истощение.
- 20 навыков с XP-кривой и реальными множителями: отдача, скорость перезарядки, скорость поиска, выносливость,
  переносимый вес, метаболизм, скрытность, крафт, хирургия… Элитный уровень — 50.
- **Баллистика**: путевая пуля с гравитацией, логистическая кривая пробития `penetration vs класс брони`,
  поглощение урона бронёй, износ брони по материалу (арамид/сталь/титан/керамика…), рикошет, фрагментация.
- **Оружие**: 16 стволов, режимы огня (один/очередь/автомат), разброс, перегрев, заклинивание (jam) зависит от
  износа, тактическая и полная перезарядка, магазины с патронами, модули (прицелы, глушители, цевьё, приклады),
  отдача в мышь и в ствол, ADS, sway, гильзы, дульное пламя.
- **Экипировка**: бронежилеты/риги/шлемы/рюкзаки/секьюрка дают зоны защиты, штрафы к скорости/повороту/эргономике
  и реально надеваются на 3D-тело (базовое тело — термобельё; костюм заменяет тело, жилет/шлем/рюкзак — оверлеи).
- **FPS-контроллер**: ходьба/бег/присед/лёжа, выносливость, штрафы от веса и ранений, хед-боб, шаги, падения.

### Инвентарь (`Runtime/Items`)
- Тетрис-сетка а-ля Тарков: размеры предметов, поворот, автопоиск места, стакирование, перенос, вес,
  вложенные контейнеры; слоты экипировки с авто-синхронизацией контейнеров (карманы/риг/жилет/рюкзак/секьюрка/сташ).
- 14 типов предметов: оружие, модули, магазины, патроны, броня, шлемы, риги, одежда, медицина, еда/вода,
  контейнеры, ключи, валюта, гранаты, семена, бартер.
- `ItemInstance` — мутабельная копия: стак, прочность, заряженные патроны, установленные модули, вложение.

### Рейд (`Runtime/Raid`)
- Таймер рейда, спавны игроков и ботов, зоны выхода с условиями (нужен предмет, время на выходе),
  40 точек лута с таблицами (general/medical/weapons), корзины лута, трупы с лутом, результаты рейда
  (Survived / RunThrough / Killed / MIA), перенос лута в сташ, страховка возвращает вещи с шансом 55 %.

### ИИ (`Runtime/AI`)
- Навигация по NavMesh, зрение (конус + периферия + проверка LOS), **слух** по глобальным событиям выстрелов,
  память о цели, реакция, точность, агрессия, фланг, перезарядка, лечение, обыск трупов.
- Профили: мародёр, контрактник, рейдер, снайпер, босс — разные пулы оружия/брони, зрение, групплы.
- Директор ботов: волны, дожим со временем, лимит живых, запрет спавна рядом с игроком.

### Убежище-бункер (`Runtime/Hideout`) — 3D, от первого лица
- Процедурно собранный бункер: коридор 40 м, 5 комнат-альковов, генераторная, водосборник, теплица с 6 грядками.
- 14 модулей × 2–4 уровня: стройка за реальное время (идёт **офлайн**, таймстемпы в сохранении), требования
  по предметам/деньгам/другим модулям, эффекты: слоты крафта, грядки, размер сташа, расход топлива, бонусы.
- Крафт: 12 рецептов (медицина, патроны, еда, расходники), очередь, скорость от уровня верстака и наличия света.
- Теплица: свет/температура/бак воды, 6 растений (картофель, морковь, травы, грибы, технические водоросли, мята),
  стадии роста, полив, удобрение, увядание от нехватки воды/света, сбор урожая и возврат семян.

### Экономика и прогрессия (`Runtime/Economy`, `Runtime/Progression`)
- 5 торговцев: ассортимент, цены, лояльность (уровень/репутация/потраченные деньги), ремонт с потерей максимальной
  прочности, страховка, продажа junk.
- Квесты: 4 цепочки, типы целей (убить, найти предмет, выжить, построить модуль, собрать урожай), награды
  (деньги, XP, репутация, предметы), прогресс считается по событиям игры.
- Профиль: уровень, XP, сташ, навыки, квесты, репутации, страховки, статистика K/D.

### Сеть (`Runtime/Meta`, `Netcode`)
- Ядро игры не зависит от сетевого пакета: `INetBackend` + `NetBackendRegistry`. По умолчанию работает
  **LocalNetBackend** — офлайн-рейд с ботами (все боты — серверные).
- `EXFIL.Netcode` — слой поверх **Netcode for GameObjects**: хост = авторитет, боты живут на сервере,
  вход по `ServerRpc`/`ClientRpc`, синхронизация состояния. Одна сборка, чтобы отсутствие пакета не ломало проект.

### UI (`Runtime/UI`)
Строится в рантайме, без префабов: HUD (здоровье по частям, выносливость, патроны, таймер, эффекты, прицел,
подсказки), инвентарь/сташ, обыск лута, крафт, теплица, посадка, генератор, убежище, торговцы, квесты,
результат рейда.

## Замена заглушек на реальные модели

Ничего переписывать не нужно: у `WeaponItemDefinition` есть поля `ViewModelPrefab` / `WorldModelPrefab`,
у `ArmorItemDefinition` и `ClothingItemDefinition` — `Visual.Prefab3D` + точка крепления (`AttachPoint`),
у `CharacterDefinition` — `BodyPrefab`, у `PlantDefinition` — `StagePrefabs` (5 стадий).
Пока поле пустое, код строит аккуратную заглушку из примитивов.

Где брать CC0-модели — [Assets/Art/MODELS.md](Assets/Art/MODELS.md).

## Известные ограничения (осознанные)

- Сгенерированный ИИ-арт требует художнической подгонки: оверлеи брони надо совместить с базовым телом,
  а листы персонажей нарезать через **EXFIL → Art → Slice selected sprite sheets by grid** (при необходимости
  **Remove background (corner colour)**).
- NavMesh печётся при сборке сцены; если пакет `com.unity.ai.navigation` не установлен — запустите
  **EXFIL → Setup → Install AI Navigation** и пересоберите сцены.
- Анимации пока процедурные (отдача, sway, перезарядка, bob). Для полноценного захватаMotion
  подключается Animator/ rig — интерфейсы для этого оставлены в `CharacterBody3D` и `FirstPersonWeapon`.
- ИИ не использует полноценный поиск пути по покрытиям: фланг/укрытие — эвристики вокруг NavMesh.
- Физика пуль — упрощённая баллистика (гравитация + путевой рейкаст), без прослойки материалов.
